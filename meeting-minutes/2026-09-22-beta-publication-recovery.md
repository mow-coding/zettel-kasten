# 자동 베타 공개 실패와 복구

사용자는 완료 상태와 고객 전달 시점의 불명확함을 다시 지적했다. PR #133 증분 검사는 통과했으나 첫 자동 베타 35614130037은 실제 설치 검증 후 공개 단계에서 실패했다. 설치 성공과 공개 성공은 별개다.

원인: 생성한 draft를 공개 tag 조회 API로 읽어 HTTP404를 받았다. 인증된 release 목록에서 정확한 tag의 유일한 numeric ID를 찾아 조회하도록 교정했다. 모호한 ID와 네트워크 실패는 부재로 취급하지 않는다. 같은 검증 wheel을 보존해 공개 단계만 복구하며 재빌드하지 않는다.

배포 도구만 바뀐 경우 제품 전체 회귀를 반복하지 않도록 전용 CI 경로를 추가했다. publisher와 전용 테스트, 분류 도구, 허용한 개발 문서만 대상이며 기존 제품 job 및 workflow 전역 설정이 동일해야 한다. 제품 파일이나 해당 실행 계약이 바뀌면 전체 경로다. Linux와 Windows에서 publisher/분류 회귀가 통과해야 필수 집계가 성공한다. 관련 합성9개 통과, 원격 적용 여부는 별도 확인한다.

공개 복구 첫 실행은 베타를 공개했으나 새 환경 pip URL 다운로드가 HTTP504로 실패했다. 익명 파일 해시 확인은 통과했으나 새 설치는 아직 성공으로 세지 않는다. 파일을 덮어쓰지 않고 동일 자산을 확인한 뒤 일시적 다운로드 실패를 재시도한다. 현재 안정판 공개와 고객 수용 완료를 주장하지 않는다.
