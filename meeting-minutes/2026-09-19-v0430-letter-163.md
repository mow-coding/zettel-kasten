## What the adversarial review changed

The privacy/receipt verdict and the regression/pins verdict both refuted the
first design. Adopted: generic receipt scan over all receipt roots (batch
item envelopes were invisible to the audit-shaped scan); writer lock plus a
minimum claim age (a started claim is exactly the state of a running
writer); "receipts only" write evidence instead of "no domain write";
receipt backfill for a crash between the swap and its receipt; no raw edge
types in the discard plan; drop the MCP create-draft attach (fail-closed
path); reuse the dry-run fidelity digest in the batch approve loop; Korean
dialog copy ending in "까요?"; the letter-137 revert-edge test retargeted;
`test_v0401`/`test_command_status`/notion pins for the conditional scope
count; README prose on `revert-edge`; global cap semantics preserved in the
unpaged audit.
