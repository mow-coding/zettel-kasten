# WOM-kit v0.4.50 — private content review for remote cleanup

This candidate extends `object-storage-cleanup` for files that were already uploaded, including older objects without an upload receipt. WOM's helper AI can request a private inventory with `include_content_samples: true`, read verified content alongside creation purpose, work records and current references, and prepare the exact classification and deletion request. The person does not have to label every remote file. The helper holds ambiguous, truncated, binary, secret-bearing or still-used files instead of guessing from a name or missing receipt.

For each selected remote object, WOM downloads the whole content once to verify SHA-256 and size while retaining at most the first 4,096 bytes for private review. That content is bound into the signed private inventory; the ordinary command result, public receipt and zet body do not contain it. The default inventory path remains content-free. Content review is limited to 4,096 objects per request, and the helper must establish the actual management scope and absence of outside writers before deletion.

The existing exact-key cleanup still checks current references and active work, deletes only the approved key, verifies absence, records uncertain outcomes for authenticated resume, and prevents later re-upload to a pending or disposed key. A separate key with identical bytes remains untouched. `object-storage-open` continues to provide a temporary read-only link with the existing default 900-second lifetime. A valid full-access grant does not gain another approval exception.

Synthetic source and installed-wheel tests cover a missing or short content sample, a single whole GET with a bounded prefix, exact selection and preservation. The isolated developer R2 test used the installed command to inspect two synthetic files, delete only the confirmed temporary file, preserve the other during cleanup, and remove both test-owned keys afterward. No customer bucket was used. Actual customer acceptance and the helper AI's behavior in a customer conversation are not yet verified. Other outstanding feedback remains open.

After publication and public-install verification, install the exact release wheel in a new environment or use the official `project-version-update` flow for a pinned project. Installing the tool alone does not change a customer archive or delete remote data.

```powershell
$womBootstrapNonce = [guid]::NewGuid().ToString("N")
$womBootstrapRoot = Join-Path $env:LOCALAPPDATA "WOM\bootstrap-v0450-$womBootstrapNonce"
py -3.12 -m venv $womBootstrapRoot
$womBootstrapPython = (Get-Item -LiteralPath (Join-Path $womBootstrapRoot "Scripts\python.exe")).FullName
& $womBootstrapPython -m pip install "https://github.com/mow-coding/zettel-kasten/releases/download/v0.4.50/wom_kit-0.4.50-py3-none-any.whl"
& "$womBootstrapRoot\Scripts\archive.exe" --version
```
