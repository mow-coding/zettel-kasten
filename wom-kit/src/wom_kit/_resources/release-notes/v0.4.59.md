# WOM-kit v0.4.59 — faster cleanup, and where the time goes

Second part of the answer to beta letter 180. A reconcile of 53 remaining items took about 61 minutes, and nothing showed where that time went. v0.4.58 finished the two stuck items and removed the per-item capacity scan; this release covers the rest of the performance requests. Installing the tool alone does not change a customer archive.

## Faster item processing

Each child step of a cleanup item rewrites one manifest row. The archive index used to delete and re-insert every row three times per item. Now it writes only the rows that changed.

- The resulting tables are exactly what a full rewrite produces; tests compare the two.
- The safety checks (lease, fence, seal and final exact-bytes check) are unchanged.

## Where the time goes

`measurements.work_timing` in the activity-cleanup result splits the processing time into categories. A nested category pauses the one around it, so the categories never overlap and add up to the total. The categories are:

- `provider_request`
- `manifest_read_parse`
- `index_projection_seal`
- `intake_capture`
- `local_hash_verify`
- `child_approval_claim`
- `lock_wait`
- `remote_verification`
- `upload_child_other`, `offload_child_other`
- `unattributed_seconds`

## Progress and ETA

Items already completed are skipped in their own `activity-cleanup-skip-completed` stage. The item count and its ETA cover only the items that still need work.

## Boundaries

All speed figures come from a synthetic archive; the customer's real archive is not measured. A shared manifest parse cache was prototyped and is not shipped, because it showed no gain. `work_timing` will show whether a real archive differs.

## Install after publication

Use the exact public release asset after its hash and size are reported:

```powershell
$womBootstrapNonce = [guid]::NewGuid().ToString("N")
$womBootstrapRoot = Join-Path $env:LOCALAPPDATA "WOM\bootstrap-v0459-$womBootstrapNonce"
py -3.12 -m venv $womBootstrapRoot
$womBootstrapPython = (Get-Item -LiteralPath (Join-Path $womBootstrapRoot "Scripts\python.exe")).FullName
& $womBootstrapPython -m pip install "https://github.com/mow-coding/zettel-kasten/releases/download/v0.4.59/wom_kit-0.4.59-py3-none-any.whl"
& "$womBootstrapRoot\Scripts\archive.exe" --version
```

Require `archive 0.4.59` from a new process, then follow the reviewed `project-version-update` flow for an existing project.
