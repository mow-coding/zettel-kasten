# WOM-kit v0.4.48 — inspect session backup scope first

This candidate fixes a session backup being blocked by a large changed file
belonging to another activity. It selects authenticated session output paths
before content, Git attribute and blob inspection. Normal unscoped backup
still inspects its whole declared scope.

The existing size limits still apply to selected files. Other activities'
working and staged changes are not committed. Structural Git state remains
part of the reviewed plan; concurrent changes can require a fresh plan.
New v4 scope receipts bind the inspected paths. Existing v1/v2/v3 receipt
validation and recovery retain their original meaning.

Synthetic verification includes more than 11,132 changed paths, an unrelated
file above the existing byte limit, selected-file limit enforcement and an
approved backup followed by resume. Native approval and remote Git transport
are injected in those tests; public installation has separate release evidence.

This is one scoped fix. Remote temporary-object deletion, provider intake and
other outstanding requests are not included in this release.
Use the exact published wheel only after its release evidence is available.
Confirm `archive 0.4.48` in a new process and use the official project update
`project-version-update` flow for an existing pinned installation.
Installing the tool alone does not change a customer archive. Customer acceptance remains separate.

```powershell
$womBootstrapNonce = [guid]::NewGuid().ToString("N")
$womBootstrapRoot = Join-Path $env:LOCALAPPDATA "WOM\bootstrap-v0448-$womBootstrapNonce"
py -3.12 -m venv $womBootstrapRoot
$womBootstrapPython = (Get-Item -LiteralPath (Join-Path $womBootstrapRoot "Scripts\python.exe")).FullName
& $womBootstrapPython -m pip install "https://github.com/mow-coding/zettel-kasten/releases/download/v0.4.48/wom_kit-0.4.48-py3-none-any.whl"
& "$womBootstrapRoot\Scripts\archive.exe" --version
```
