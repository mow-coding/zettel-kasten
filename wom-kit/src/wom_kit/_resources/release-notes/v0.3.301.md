# WOM-kit v0.3.301

Release date: 2026-08-07

## Letter 112 real-use completion

- Added strict, receipt-backed `zettel-objet-link` and exact-byte revert paths,
  plus a full-SHA `assets` schema and truncated-hash mint blocker.
- Added GFM table conversion, simple Notion column flattening, and paired
  `mention-date` visible-text preservation to markup normalization. Ambiguous
  or unknown semantics still fail closed.
- Extended external locator identity with optional service, account, and
  occurrence coordinates while preserving v0.1 reads and never echoing private
  coordinate values.
- Added `authoring-conventions`, human-record integrity guidance, openable-file
  claims, in-place draft revision rules, and mint review warnings for likely
  tool traces or contradictory status prose.
- Added receipt-backed `discard-draft` and exact restore for never-minted inbox
  drafts; minted/canonical material remains out of scope.
- Made source-intake plan paths archive-root relative, made matching records
  idempotent, distinguished same-shape local files without reading their
  content, and added a 1-1,000 item `source-intake-batch` review gate.
- Expanded relation candidate signals to existing date and category facets
  without echoing their values or inferring edges.
- Made JSON-mode missing-argument errors content-free stdout JSON with empty
  stderr.
- Added Draft 2020-12 schemas, packaged runtime guidance, focused regressions,
  and the public [Letter 112 completion contract](https://github.com/mow-coding/zettel-kasten/blob/main/wom-kit/docs/letter112-completion.md).
- Prepared a consolidated, human-run
  [Letter 112 beta retest protocol](https://github.com/mow-coding/zettel-kasten/blob/main/wom-kit/docs/letter112-beta-retest-protocol.md)
  without contacting or opening the beta tester's private archive.

## Safety and truth boundaries

All new mutations are CLI-only, human-reviewed, deterministic-plan-bound, and
receipt-backed. They do not call providers. Batch source intake reads metadata
only, not file bodies or content hashes. Unknown markup, unsupported table
semantics, truncated objet identifiers, stale plan hashes, and unrelated later
file changes block rather than being guessed through.

This release is engineering-complete only after the release gates pass. A beta
tester's private-archive rerun remains a separate human real-use validation
step and is not performed or claimed by this repository release.
