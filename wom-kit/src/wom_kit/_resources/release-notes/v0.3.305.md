# WOM-kit v0.3.305

Letters 113 and 114 real-use completion.

## Included

- ready-only markup plans and approved writes without changing blocked zets;
- reviewed manifested-objet bindings for file, audio, and video fragments;
- strict ISO mention-date, synced-block snapshot, and numeric-column/header
  table normalization rules;
- in-place locator coordinate enrichment without an active duplicate;
- 5,000-row title-remap plan/write defaults and a provenance-bound short exact
  source-title exception.
- creation-time abstract/facet requirements for AI drafts and a bounded
  same-title inbox duplicate guard;
- privacy-safe unpublished-draft attention in every `ai-start-here` session;
- runtime, authoring, and response rules that make publication complete only
  after approved canonical plus receipt evidence and require immediate blocker
  reporting.

## Safety boundaries

- strict all-clear markup behavior remains the default;
- unresolved references and unsupported semantics still block;
- objet ids must be full SHA-256 ids already present in the manifest;
- locator conflicts and ambiguous occurrences never overwrite;
- short human-written titles do not bypass the specificity gate;
- no provider, credential, canonical beta archive, or UI write is performed by
  the release itself.
- human-owned rough drafts remain possible; the stricter creation block applies
  only to declared AI-assisted/generated routes;
- no automatic draft repair, semantic merge, discard, or mint is performed.

See `docs/letter113-completion.md` and `docs/letter114-completion.md` for the
operator workflows.
