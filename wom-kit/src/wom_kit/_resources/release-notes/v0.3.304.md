# WOM-kit v0.3.304

v0.3.304 is a focused patch for the project updater defect reported in beta
Letter 112 section 10. A project pinned at v0.3.300 can now preview and approve
an update to v0.3.301 even when the command happens to be running from a newer
external WOM-kit checkout.

## Fixed

- `project-version-update` now evaluates its forward-only rule from the
  recognized project pins and the project-local source mirror versions: the
  state that the transaction can actually change.
- The already loaded WOM-kit runtime remains visible as context but never
  makes an otherwise forward project update look like a downgrade.
- A newer runtime loaded outside `.zettel-kasten/source` produces an explicit
  warning that it is informational and is not a forward-only blocker.
- A real downgrade of either a recognized project pin or a project-local
  source version still fails closed.
- Structured results now state the comparison basis, recognized project
  version count, target comparison result, and that the running runtime was not
  used for the decision.
- A real forward-only blocker now gives an actionable next step instead of
  only saying to resolve the blocker.

## Safety Boundary

This patch changes no archive, zet, objet, manifest, locator, or receipt
schema. The dry-run remains no-write and performs no fetch. Windows approval
retains the existing exact-tag, configured-origin, clean-tree, path,
quiescence, checkpoint, receipt, and rollback gates.

The running process is not reloaded. A successful approved update still
requires a new process and `archive version <project-or-archive-root> --format
json` before the target runtime is claimed active.

## Compatibility

Additive output and a bug fix. Existing v0.3.303 archives require no migration.

## Verification Contract

Release acceptance requires a regression that reproduces a newer external
runtime over an older project pin, a separate true-downgrade regression,
focused updater tests, the complete platform matrix, release-readiness and
packaged-resource checks, an exact-tag wheel, and one anonymous fresh install.
