# 오브제 정리 범위 결정 — 2026-09-21

- 사용자 확정: 기본 작업 범위는 현재 세션에서 다룬 객체다. 현재 세션이 포함된 전체 집합으로 대체하지 않는다.
- 사용자 추가 확정: 다른 세션의 일을 명시적으로 맡겼다면 함께 처리할 수 있어야 한다. 다른 세션을 무조건 금지하지 않는다.
- 구현 선택: 자동으로 증명 가능한 capture/승인 기록을 사용하며, 과거 출처 미연결 자료와 여러 세션의 합집합은 정확한 객체 목록으로 선택한다. 특정 세션 및 전체 선택도 명시적으로 지원한다. 선택 근거가 없으면 범위를 확대하지 않는다.
- 승인 정책 유지: 전체 액세스의 창 없는 실행은 유지한다. 데이터 선택과 승인 방식은 별도 계약이다.
- 중단 처리: 부분 업로드는 기존 효과와 영수증을 보존한 포기로 기록하고 새 좁은 계획으로 넘어간다. 무효과 finalize나 원래 전체 실행 강행으로 대신하지 않는다.
- 검증과 출시: 합성 재현과 실제 CLI 연결을 검사한다. 구현·로컬 검증·CI·공개출시·고객 확인을 구분한다.

구현 계약과 사용 안내는 [오브제 범위 문서](object-storage-session-scope.md)에 있다.

- CI 교정 결정: 원본과 미러의 LF 규칙을 유지하고 생성 지문을 실제 Git 바이트와 대조한다. 검사를 완화하거나 CI를 우회하지 않는다.
