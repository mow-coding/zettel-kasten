# 피드백 완결 구현 결정

## Notion 연결 방식

상태: 사용자 확정, 현재 적용.

Notion은 사용자가 제공하는 PAT를 기존 안전한 자격증명 등록과 OS 보관소로 관리한다. 새 세션에서 회수하여 첨부 수집과 연결 근거 반입에 사용한다. 공용 앱, 브라우저 OAuth, 인증 서버는 이번 구현 범위에서 제외한다. PAT 사용에 별도 WOM 인증 서버를 요구하지 않는다. 이전 공용 앱 제안은 이 결정으로 대체한다.

검증은 합성 자료 및 명시적으로 제공된 개발 환경에서 수행한다. 토큰과 고객 자료를 공개 기록에 남기지 않는다.
