# WOM-kit v0.3.294: Checked-Layer Objet Rediscovery

Release date: 2026-07-31

## What Changed

v0.3.294 adds a read-only evidence plan before any AI claims that a preserved
original, source file, or objet does not exist:

```text
archive objet-rediscovery-plan <archive-root> <query> --dry-run --count-total --format json
```

The same contract is available through the read-only MCP tool
`objet_rediscovery_plan`.

## Honest Search Boundary

Ordinary `archive search.complete` is unchanged. It means only that the
current generated SQLite result set was not truncated by the requested limit.
Even `--count-total` proves only an exact count inside that index snapshot.

The new result preserves those values under `index_search` while separately
reporting:

```text
status: search_incomplete
rediscovery_complete: false
negative_claim_supported: false
```

An index-only zero result is never promoted to global `not_found`.

## Ten Fixed Layers

The result always lists indexed zettels, object manifests, derived text,
views, source records, zettel-to-objet edges, private original-name metadata,
approved external local stores, external-store evidence, and unrecovered
source references in one deterministic order.

The first five are independently probed SQLite snapshot evidence only, so an
early channel filling the global result limit cannot hide an unavailable later
channel. Current index-health does not prove searchable zettel title/body
freshness or non-zettel source freshness. Zettel-to-objet traversal remains
unchecked without a reviewed zettel selection. The four
private/external/reference contracts remain explicitly not implemented rather
than being treated as absent.

## Privacy And Failure Boundary

JSON, text, and MCP summaries do not echo the query, query hash, search rows,
filename, title, body, snippet, source/object/zettel id, local path, provider
locator, secret value, or exception text.

Invalid archive identity, missing or malformed SQLite, expected permission or
decoder failure, non-empty pending WAL or rollback-journal content, an unsafe
symlink/junction/reparse directory boundary, and an index that changes during
inspection return the same fixed `blocked` result family with ten layers and
process exit 1.

The command uses an immutable plan-only SQLite snapshot read so it creates no
WAL/SHM sidecar. Its local zettel walker blocks reparse descent before an
external directory can be enumerated. It performs no index rebuild, file
write, objet-byte read, external-directory scan, provider/network/credential
call, Runtime Skill installation, or `AGENTS.md` rewrite.

## Routing And Compatibility

AI action routing advances to
`wom-kit/ai-command-path-routing/v0.8` and adds:

```text
plan_objet_rediscovery_before_negative_claim
```

v0.3.293 runtime-guidance readiness, host-consumption `not_proven`, and the
complete operator-feedback human-review sequence remain unchanged. Ordinary
search and index-health public contracts remain compatible.

## Deferred Work

v0.3.294 does not implement private original-name normalization or metadata
writing, approved external-store registration, external scanning, exact
external resolver/open verification, provider download, or source-reference
coverage. Those remain separate reviewed v0.3.295-v0.3.299 batches.
