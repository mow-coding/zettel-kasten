# WOM-kit v0.4.47 — activity recovery and concurrent archive work

This candidate connects cleanup recovery, Windows stream preservation,
large scoped Git backup, external intake and consistent search pages.
Installing the tool alone does not change a customer archive.
Publication and customer acceptance require their own evidence; this source
document does not assert that a downloadable release exists.

## Finish the selected activity

- `activity-cleanup --status` distinguishes completed, pending, replaced and
  unexplained missing files. `--reconcile --dry-run|--approve` handles only the
  unfinished selection without rewriting the original intent.
- Windows alternate data streams are preserved with the body. The official
  `--restore-item` route reconstructs both in a new file, and `--resume` verifies
  an interrupted publication without overwriting a different destination.
- Classify before backup: proven disposable temporary files are discarded
  without intake/upload. Ambiguous files are retained without upload/deletion.
  Names, extensions and age alone are not disposal evidence.
- Large Git attribute queries use bounded batches; exact add/commit selections
  use literal NUL-delimited input. Other activities' staged and working changes
  remain outside the declared backup selection.
- `session-handoff-checkpoint --cleanup-request` binds original cleanup and
  body/stream preservation evidence to the handoff. Partial evidence remains
  partial; missing original evidence is a development-wait state.

## Work during another session's transfer

- New upload/offload/restore and source-intake operations hold target leases
  while copying or transferring. Shared registry, manifest and index updates
  retain their publication checks. Same-target drift does not authorize a new
  selection, and waits are bounded instead of stealing lock files.
- `source-intake-batch --stage-external` copies the exact approved external
  source to managed staging, checks it and connects to the existing capture
  flow. Originals are never moved, modified or deleted by this intake route.
- Search and `find-objet` provide cursors tied to a verified historical index
  generation. Keep query/filter/page size unchanged when following a cursor.
  The response states counts and observation time; search is not backup proof.
- `work-session --action inspect --caller-status` separates the saved grant,
  current process capability, observed execution and installation alignment.
  Inspecting never grants permission or borrows another conversation's grant.
- A valid full-access grant does not open additional approval dialogs for
  legacy-identifier warnings. Domain quality checks and warning evidence remain.

## Progress and boundaries

Results separate approval resolution, activity-writer wait, processing time,
completed/retained/unprocessed items, payload bytes and actual provider request
observations. Failed or unmeasured transfer bytes and physical disk recovery
are not guessed from file sizes. Exact-byte manifest generations reuse parsed
lookups while retaining content-change detection and remote verification.

Old approved execution records retain their recovery contracts. Remote temporary
object deletion is not introduced. Windows performs native cleanup; unsupported
platforms retain planning/classification without pretending deletion occurred.
Two customers' replies and acceptance remain independent.

Use the exact published wheel only after release evidence supplies its SHA-256,
size and public-install result. Confirm `archive 0.4.47` in a new process, then
use the official `project-version-update` flow for a pinned project runtime.

```powershell
$womBootstrapNonce = [guid]::NewGuid().ToString("N")
$womBootstrapRoot = Join-Path $env:LOCALAPPDATA "WOM\bootstrap-v0447-$womBootstrapNonce"
py -3.12 -m venv $womBootstrapRoot
$womBootstrapPython = (Get-Item -LiteralPath (Join-Path $womBootstrapRoot "Scripts\python.exe")).FullName
& $womBootstrapPython -m pip install "https://github.com/mow-coding/zettel-kasten/releases/download/v0.4.47/wom_kit-0.4.47-py3-none-any.whl"
& "$womBootstrapRoot\Scripts\archive.exe" --version
```
