## Write contract

The writer requires the exact private request SHA-256, the exact read-only
review-plan SHA-256, a safe human reviewer, and the explicit
`--affirm-memberships-reviewed` flag. It recomputes the write set before and
after taking an exclusive lock.

Before changing any canonical file, WOM preserves verified content-addressed
before-snapshots and publishes a prepared private journal. It changes only
`facets.activity_group`, uses atomic file replacement, verifies every final
hash, and publishes the immutable receipt last.

Handled failures roll back to exact before bytes. Evidence remains after a hard
interruption so the separate recovery plan can classify lock-only, unstarted,
partial, fully applied, completed-residue, or unknown-drift states.

## Safety boundary

Recovery requires its own current plan digest, human reviewer, approval, and
affirmation. It can clean verified residue or restore a partial transaction to
verified before bytes. Unknown drift is a manual forensic hold.
The recovery digest binds the global writer-lock state. Recovery and the writer
cross-check the recovery guard and the same global writer lock; when a complete
journal has lost its lock, recovery must claim that lock exclusively before it
can proceed.

The release adds memberships only. It does not remove memberships, infer
members, edit the event anchor, expose an MCP writer, call providers or models,
use the generated index, or return private ids, paths, titles, facet values,
bodies, or reviewer identity in command output.
