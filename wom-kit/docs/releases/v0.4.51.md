# WOM-kit v0.4.51 — feedback-completion integration (letters 174-176)

This release lands the work that answered beta letters 174, 175 and 176 after the v0.4.47-v0.4.50 partial releases. Installing the tool alone does not change a customer archive; use the reviewed `project-version-update` flow for a project.

## Registration after external staging

A failed `objet-capture-batch` now keeps its cause, stage, approval and write state and returns an `operation_ref`. `--resume` with the original approval finishes only the unfinished items. It does not open a second dialog or re-copy staged bytes, and a changed staged file never registers under the old approval.

## Long operations can be cancelled and inspected

`operation-control --action cancel` now requests cooperative cancellation for capture batches, remote upload, offload, restore, local-only preservation and activity cleanup. Each tracked run keeps its result artifact for inspection and for the command's own resume. A cancel request is not a completed stop.

## Session caller status

`work-session --action inspect --caller-status` tells a caller whose process ended apart from an expired or foreign grant and names the official next step. It does not borrow another session's grant.

## New review commands

- `title-diagnostics`: every title verdict and its reason, paged over a retained snapshot.
- `human-artifact-inventory`: every human-made file, paged, with a reviewed batch registration.
- `draft-disposition`: hold a draft with its reason, conditions and next action. It never publishes or deletes.
- `feedback-closure-check`: checks each requested outcome against installed-flow, release and reply evidence.
- Relation-candidate batches with revert.

## Provider intake (Notion PAT only)

- Notion attachments and media.
- Notion connection evidence (`connection-evidence-import`).
- Mailbox fetch across accounts.
- Tiro transcripts and audio (`tiro-content-import`).

Each keeps exact bytes and provenance and reuses material that was already imported. Notion uses the adopted personal access token only; there is no public app or authorization server.

## Boundaries

These changes were validated with synthetic data and simulated providers and approval windows. Real provider accounts, the physical Windows dialog and customers' own runs are not confirmed. The original-filename search after capture (A17) and the A14 performance targets remain open. Letters 174-176 stay open until each requested outcome is confirmed.

## Install after publication

Use the exact public release asset after its hash and size are reported:

```powershell
$womBootstrapNonce = [guid]::NewGuid().ToString("N")
$womBootstrapRoot = Join-Path $env:LOCALAPPDATA "WOM\bootstrap-v0451-$womBootstrapNonce"
py -3.12 -m venv $womBootstrapRoot
$womBootstrapPython = (Get-Item -LiteralPath (Join-Path $womBootstrapRoot "Scripts\python.exe")).FullName
& $womBootstrapPython -m pip install "https://github.com/mow-coding/zettel-kasten/releases/download/v0.4.51/wom_kit-0.4.51-py3-none-any.whl"
& "$womBootstrapRoot\Scripts\archive.exe" --version
```

Require `archive 0.4.51` from a new process, then follow the reviewed `project-version-update` flow for an existing project.
