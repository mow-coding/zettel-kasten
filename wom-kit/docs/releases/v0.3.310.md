# WOM-kit v0.3.310

Letter 117 reviewed imported-reference and protected-literal completion.

Status: v0.3.310 implementation and release scope. This source note does not
replace independent CI, exact-tag, GitHub Release, packaged-resource, wheel,
or fresh-install evidence.

## Added

- exact lowercase, attribute-free, self-closing
  `unknown:synced_block`, `unknown:transclusion_reference`, and
  `unknown:transclusion_container` occurrences can use reviewed
  binding-manifest v0.2 authority for one static canonical
  `zettel_reference` or fully manifested `objet`;
- an empty paired `database` with strict required `inline`/`url`, optional
  `data-source-url`, no extra attribute, and whitespace-only inner content can
  use one reviewed `zettel_reference`; and
- protected-literal detection now covers normalizable-looking markup in quoted
  HTML attributes, unreviewed CommonMark raw-HTML type 6/type 7 blocks and
  their Markdown containers, multiline-label reference definitions, and
  continued reference destinations/titles, with adversarial linear-time
  regression coverage.

## Safety boundary

- repeated same-digest reference shapes still require complete per-zettel
  1-based `occurrence_index` authority;
- synced/transclusion output is a static zettel or objet link, not an edge,
  live-sync claim, provider import, or reconstruction of omitted children;
- database output is static zettel navigation, not a materialized database view;
- malformed/alternate placeholder spelling, attributes, paired unknown forms,
  self-closing or content-bearing databases, invalid database attributes,
  incompatible binding kinds, stale targets, and incomplete/unused authority
  remain fail closed;
- callout icon/color/indentation semantics, unknown column structure, and
  unsupported unknown content remain byte-identical and deferred;
- a protected context or any other blocker restores the complete original
  zettel body; protected literals are expected terminal content, while partial
  safe outside-span normalization is not implemented; and
- there is no provider/network call, credential read, live Notion lookup,
  objet-body read, edge write, archive migration, canonical beta write, MCP
  writer, or UI change.

## Read-only evidence

The reviewed beta snapshot contained 419 exact synced/transclusion placeholder
occurrences across 165 zettels. Nine protected literal occurrences were
excluded before binding review, leaving a maximum candidate lane of 410
occurrences across 156 zettels. These are raw-presence and upper-bound candidate
counts, respectively—not ready counts, approved bindings, apply receipts, or
migration evidence. The archive remained read-only.

## Compatibility

Existing v0.2 manifests, plan/apply/recovery/revert commands, snapshots,
journals, receipts, and exact-byte revert behavior remain in place. There is no
manifest-schema revision, new command, or automatic archive migration.

## Release evidence boundary

Source documentation and local implementation checks are not release proof.
Tag identity, synchronized packaged resources, release CI, wheel inspection,
fresh isolated installation, and the public GitHub artifact remain separate
gates.
