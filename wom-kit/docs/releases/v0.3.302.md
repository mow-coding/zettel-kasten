# WOM-kit v0.3.302

Release date: 2026-08-07

## Saved-view lifecycle and fail-closed authority

- Added CLI-only `saved-view-write` for one closed private request under
  `.wom-scratch/private/saved-views/`.
- Required an existing current index, recognized navigation facets, at least
  one current non-redacted match, a safe reviewer, explicit human review
  affirmation, and the exact fresh plan SHA-256.
- Bound each plan to the raw and canonical request, the complete saved-view
  authority, rendered YAML bytes, deterministic no-overwrite target, and
  current match count.
- Added an immutable content-free write receipt and a freshly reviewed
  missing-receipt finalization path after interruption.
- Added `saved-view-revert`, which removes only exact unchanged writer-owned
  bytes, records a separate immutable receipt, and uses a short transaction
  journal to converge after interruption.
- Replaced silent saved-view parse skipping with a bounded fail-closed
  authority scan. Invalid UTF-8/YAML, unsafe or oversized entries, invalid ids
  or filters, and duplicate ids now block view execution, recommendation,
  writes, and reverts.
- Updated Doctor, AI command-path routing v0.11, new-archive AGENTS templates,
  public documentation, package resources, and Draft 2020-12 request,
  receipt, and journal schemas.

## Safety and compatibility

Existing valid v0.3 view files remain readable and are never rewritten by the
new writer. Existing archives require no automatic migration. A previously
malformed, unsupported, unsafe, or duplicate view definition may now block
instead of disappearing; repair it under human review before relying on saved
views.

Ordinary plans, diagnostics, and receipts expose hashes, counts, generated
archive-relative paths, and fixed classifications without view names, facet
values, zettel titles or bodies, absolute local paths, tokens, or provider
calls. No MCP writer, index rebuild, zettel mutation, object access, provider
operation, background service, or UI change is included.
