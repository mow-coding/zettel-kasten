# WOM-kit v0.3.306

Retired external coordination integration cleanup.

## Included

- removed the former optional MOW Harness recommendation, unavailable external
  repository link, dedicated compatibility guide, and install/update/activation
  instructions from active public onboarding;
- confirmed there is no MOW Harness dependency, import, subprocess invocation,
  MCP surface, schema, bundled CLI, receipt parser, or UI in WOM;
- added the generic repository-checker source alias
  `LOCAL_ONLY_COORDINATION_STATE` while preserving the exact historical
  `LOCAL_ONLY_COLLAB_HARNESS` machine-output and import compatibility label;
- retained `collab/` and legacy `/.mow-harness/` as defensive local-state
  quarantine paths so existing prompts, mailboxes, installer metadata, or
  secrets do not enter WOM records, indexes, backups, or public Git surfaces;
- replaced the former documentation-presence regression with retirement,
  no-dependency, default-root quarantine, and exact-byte-preservation coverage;
- closed a CI false-green gap by explicitly running all six pytest-native
  modules and automatically checking that future top-level pytest function
  modules cannot be omitted from the workflow;
- corrected `objet-capture --selection` guidance to use the archive root, not
  the process working directory, and updated branch-protection documentation
  to the active `main-required-ci` / `Required CI` state.

## Compatibility and safety

- no archive migration is required;
- no WOM CLI command, MCP tool, schema, zet, objet, receipt, manifest, index,
  provider, or canonical write contract changes;
- default archive-root Doctor checks, source discovery, restore copying, and
  repository artifact-hygiene recursion exclude `collab/` and `.mow-harness/`;
  the artifact checker also refuses either root as its direct target;
- explicit file-capture and staged-folder commands retain their own reviewed
  path authority and must not be pointed at either quarantine root;
- old local state remains ignored even though the external integration is no
  longer recommended or supported;
- historical release notes and the superseded v0.3.253 decision remain as
  history, not current product guidance;
- installation of this release writes no archive and does not execute a WOM
  provider call; the package installer may contact the chosen wheel URL and
  dependency indexes to resolve the wheel's declared dependencies.
