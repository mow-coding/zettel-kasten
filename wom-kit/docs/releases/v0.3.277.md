# v0.3.277 - Notion Import Locator-Loss Census

Date: 2026-07-28

WOM v0.3.277 adds a read-only census for historical Notion imports whose
provider locators were replaced by `[source locator omitted]`.

## Added

- `notion-import-locator-loss-audit` and alias
  `notion-locator-loss-audit`.
- Complete aggregate counting across non-redacted imported Notion zets.
- Comparison of current body marker counts with import-time frontmatter
  counts.
- Content-free count states for exact and mismatching zets.
- Presence-only verification of the private `source_page_id` join key.
- Allowlisted import-family buckets and bounded issue-first item output.
- Optional content-free `--progress` output for full-archive scans.

## Safety And Privacy

- CLI-only, read-only, and `--dry-run` required.
- Reads body text only to count the exact fixed omission marker.
- Echoes no body text, surrounding context, provider URL, source-page id,
  raw frontmatter value, page title, secret, or absolute local path.
- Reads no source mirror, source map, object bytes, or download ledger.
- Calls no provider/model and writes no zet, edge, facet, receipt, index, or
  diagnostic.

## Explicit Remaining Boundary

v0.3.277 does not reconstruct provider locators and does not implement a
retroactive body writer. A later source-evidence plan must align retained
source occurrences with current markers. Count-mismatch zets remain excluded
from automatic restoration proposals.
