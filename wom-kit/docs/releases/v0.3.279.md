# v0.3.279 Pre-Release

Date: 2026-07-29

## Summary

v0.3.279 adds a bounded, privacy-safe, read-only signal for AI-declared inbox
drafts whose metadata conflicts with the current official `create-draft`
output shape.

## Added

- `archive inbox-pipeline-audit <archive-root> --dry-run --format json`
- alias `draft-pipeline-audit`
- result schema `wom-kit/inbox-pipeline-audit/v0.1`
- aggregate full-Doctor signal
  `possible_out_of_pipeline_inbox_draft`
- `wom-kit/ai-command-path-routing/v0.2` with the official audit route

## Classification Boundary

- `pipeline_shape_consistent` means current shape compatibility, not proof of
  command execution.
- `possible_out_of_pipeline_draft` means an AI-declared draft conflicts with
  one or more deterministic current output facts.
- `insufficient_evidence` means the available metadata cannot support an
  honest classification.

Missing optional `draft_creation` is neutral. A known official unprofiled
v0.3.275 `create-draft` result does not contain that block.

## Privacy And Boundedness

- top-level `inbox/*.md` only;
- maximum 5,000 drafts;
- maximum 256 KiB frontmatter bytes per draft;
- maximum 500 returned findings;
- raw paths, ids, titles, actors, source values, and bodies omitted;
- path SHA-256 and content-free reason codes retained;
- no partial over-bound population reported as complete.

## Safety Boundary

The command and Doctor stage write nothing. v0.3.279 performs no rename,
rewrite, delete, retire, mint, promote, automatic repair, provider/model call,
network call, index/database read, credential-store read, or Git action.

Any future repair must be a separate preview, human approval, exact replay,
and receipt workflow.

## Upgrade

No archive migration is required. Run the audit directly, or run full
`archive doctor --strict`. Review possible cases with the archive owner and do
not modify a historical draft merely to silence the warning.
