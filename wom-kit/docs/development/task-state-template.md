# 현재 작업표 양식

상태: 지금 사용할 수 있는 수동 인수인계 양식. 자동 저장·교대 도구는 아직 없다.
규칙: [공통 작업 규칙](README.md). 다음 본문을 로컬 `meeting-minutes/development-current-task.md`에 복사한다.
기존 작업이 있으면 덮어쓰지 않고 이어서 갱신한다. 여러 작업이면 작업별 파일을 만들고 현재 작업표에
각 파일·소유자·상태를 목록으로 연결한다. 종료한 작업의 회의록과 증거는 보존한다.

공개본에는 비공개 원문 위치와 실제 계정·경로를 넣지 않는다. 이 양식 자체에는 합성 값과 빈칸만 사용한다.

## 인수자의 실행 순서

1. 현재 사용자 지시와 공통 규칙을 읽고 위 표의 범위를 확인한다.
2. Git 상태와 작업표에 적힌 실행 중인 작업을 대조한다. 보호하라는 CI를 임의로 조작하지 않는다.
3. 기록과 다르면 차이를 적고 현재 사실을 기준으로 진행한다. 파일을 복구하거나 검사를 재실행해서 기록에 맞추지 않는다.
4. 이미 끝난 조사·검증을 재사용한다. 위 표의 다음 행동부터 승인된 범위에서 계속한다.
5. 다음 작업 단위를 끝내면 갱신한다. 같은 요약을 사용자에게 다시 작성해 달라고 요청하지 않는다.
